# Новая функциональность (фича) - создать модуль транзакций

## Проект
Next.js + nest.js + postgresql + Prisma. 
Что уже есть: User, авторизация JWT, модуль категорий + frontend авторизация. 

## Задача
Создай TransactionsModule - центральный модуль приложения для учёта доходов и расходов

## Модель данных
Транзакция должна содержать количество средств, тип, (доход или расход), описание, дату транзакции, привязку к категории и пользователю, также служебные поля на твоё усмотрение.
Обновить модели User и Category соответственно (добавить транзакции). После изменений схемы сделай и примени миграцию(и)
Создай соответствующие эндпоинты: получение списка транзакций, создание транзакции, удаление транзакции, обновление транзакции, получение конкретной транзакции и summary - агрерация транзакций по month и year.
